# Python Divide Program with Error Handling

A simple Python program that takes two numbers from the user, divides them, and displays the result.  
The program includes error handling to prevent crashes in the following cases:

- **Division by zero (ZeroDivisionError)**
- **Non-numeric inputs (ValueError)**


---

## 📌 Features
- User input for two numbers
- Handles division by zero
- Handles non-numeric input
- Displays a success message even if an error occurs


---
